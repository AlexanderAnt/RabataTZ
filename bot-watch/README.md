# bot-watch

Поиск скоординированного неаутентичного поведения (CIB) в комментариях YouTube
русскоязычных балтийских СМИ. Первые цели — каналы Delfi:
[@rus_delfi_lv](https://www.youtube.com/@rus_delfi_lv) (Латвия),
[@rudelfi_lt](https://www.youtube.com/@rudelfi_lt) (Литва),
[@rusdelfi9725](https://www.youtube.com/@rusdelfi9725) (Эстония).

## Принципы

- **Ищем координацию, а не мнения.** Никто не попадает в отчёт за взгляды. Сигналы только
  поведенческие: одинаковые тексты от разных аккаунтов, синхронная активность, аккаунты,
  созданные пачкой.
- **Кластер — это зацепка, а не приговор.** Каждый случай проверяется вручную.
- **Никакой деанонимизации.** В отчётах аккаунты показаны псевдонимами (`a_1234abcd`).
  Владельцев не ищем. Подтверждённые сети отправляем в жалобы YouTube.
- **Только легальный доступ.** Официальный YouTube Data API. Сайт rus.delfi.lv запрещает сбор
  комментариев в robots.txt, поэтому его не трогаем.
- Сырые данные (`data/`) в репозиторий не попадают.

## Запуск

```bash
export YOUTUBE_API_KEY=...          # или сетевой секрет среды
python collect.py --handle rus_delfi_lv --since 2026-06-01 --max-videos 300
python collect.py --handle rudelfi_lt  --since 2026-08-01 --max-videos 300
python analyze.py data/rus_delfi_lv data/rudelfi_lt
python -m pytest tests
```

Квота API — 10 000 единиц в сутки; один запрос (до 100 комментариев) стоит 1 единицу.
Если квота кончилась, сборщик продолжит с того же места при следующем запуске.

## Сигналы

| Сигнал | Как считается | Ложные срабатывания |
|---|---|---|
| Копипаста | MinHash по символьным 5-граммам, Jaccard ≥ 0.7, текст ≥ 40 символов, ≥ 2 разных аккаунта | цитаты, лозунги, репост одной ссылки |
| Совместная активность | пара аккаунтов комментирует одно видео с разницей ≤ 15 мин на ≥ 3 видео | постоянные зрители, которые смотрят всё сразу после выхода |
| Даты создания | разброс дат создания аккаунтов в группе против случайных групп того же размера | старые аккаунты, купленные пачкой, выглядят «нормально» |
