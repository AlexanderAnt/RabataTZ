# OSINT: Hive ransomware — рабочее досье

Цель: собрать публичную первичку по Hive и её преемникам и составить список открытых зацепок.
Rewards for Justice / Transnational Organized Crime Rewards Program (февраль 2024):
до $10M за информацию об идентификации или местонахождении лидеров Hive,
до $5M за информацию, ведущую к аресту или осуждению любого участника.

## Правила проекта

1. Только публичные источники. Никаких взломов, покупки слитых баз, регистрации
   на закрытых площадках под легендой и контактов с участниками группы.
2. Каждая связь между сущностями подкреплена URL. Без URL это не факт, а гипотеза,
   и она живёт только в `leads.md` с пометкой `HYPOTHESIS`.
3. Не публикуем имена людей, которые не названы властями. Неназванный подозреваемый
   остаётся «неназванным», даже если кажется очевидным.
4. Любая атрибуция реального человека уходит **только** в канал RFJ/FBI
   (tips.fbi.gov, контакты на rewardsforjustice.net). Не в соцсети, не на GitHub.

## Статус проверки (важно)

Сессия собрана 2026-10-13 в облачном контейнере, где сеть пропускала только поиск:
justice.gov, cisa.gov, ic3.gov, bitdefender.com, therecord.media, securityaffairs.com
не открывались. Поэтому:

- `verified: search` — факт взят из поисковой выдачи по указанному URL, но сама страница
  не открыта. **Перед использованием открыть URL и сверить дословно.**
- `verified: primary` — пока таких нет.

Первый шаг следующей сессии: открыть все URL из `sources/sources.md`, сохранить
PDF/HTML-копии в `sources/` и перевести строки в `verified: primary`.

## Файлы

- `sources/sources.md` — реестр источников (что в каждом, статус)
- `entities.csv` — сущности: ник, домен, CVE, группа, связи, у каждой URL
- `timeline.md` — хронология с источниками
- `leads.md` — открытые зацепки с приоритетом и отдельный блок гипотез
